Saving a Proxmox Instance and Wiping the Disk

Author: Colton Hooks

Date: 9/23/2026

Abstract

This paper covers backing up VMs within Proxmox, compressing the Proxmox OS, moving everything to a new machine for storage, verifying each part, and sanitizing the disk to relinquish control.

Overview

You may be faced with sending a machine or hard drive out of your possession, but you want to preserve the contents, and ensure that they won't easily be recovered. This paper describes the process of creating backups for VMs that are running on Proxmox, then moving the base OS (with configurations) to another machine for long term storage. This will allow everything to be set up on new hardware at some point in the future. Finally, after Proxmox has been packaged up, the existing SSD is sanitized using Block Erase, which goes below the filesystem/OS level, and destroys the physical electrical charge that represents the data stored.
