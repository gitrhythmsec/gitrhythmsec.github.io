What is BasicAPI?

BasicAPI is a how I am teaching myself API development, methods, and security. I am also using it as a chance to practice and develop my Python skills.


The current status is pretty simple, it has a few endpoints that simply return a string, change that string, or greet you (or whoever you shoutout). Below is a list of all of the endpoints, their methods, and their functions.

Method Endpoint Arguments:type Function
DELETE /remove None Deletes whatever is stored in static_str
GET /get-greeting name:str Greets whatever you put in "name"
GET /get-message None Returns, "Hello world! This is my first API!"
GET /get-string None Returns whatever is stored in static_str
POST /add text:str Appends whatever you put in "text" to static_str
PUT /change text:str Replaces static_str with whatever you put in "text"
