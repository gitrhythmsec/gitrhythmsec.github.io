Hardware / Networking

Arduino Network Scanner

Completed experiment

A small network-scanning project built with an Arduino Uno, Ethernet Shield 2 using the W5500, and a 16x2 I2C LCD. The project explored DHCP, subnet calculations, ICMP scanning, network discovery, and displaying results on constrained hardware.

The physical project has since been disassembled, but I plan to document what I built and the lessons learned from the experiment.
