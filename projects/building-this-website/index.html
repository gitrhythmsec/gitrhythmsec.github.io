Building This Website

By Colton H.Status: Active

Overview

This website is both a place to share my work and a project of its own. I'm using it to learn Git, GitHub workflows, responsive web design, and GitHub Pages while documenting technical projects, research, experiments, and things I learn.

This is an active project. The site and this write-up will continue to evolve as I add content and work on the design.

Why I Built It

I wanted a place to collect my research and show what I'm learning. Projects, articles, and papers give different kinds of work a home, from a practical Proxmox backup guide to a search for an internet-connected toaster.

Current Architecture

The site uses static HTML pages and one shared stylesheet, with no JavaScript or external libraries. Each section has its own directory and index.html file. Individual articles, papers, and project write-ups live in subdirectories, and the Proxmox paper includes a downloadable PDF.

The navigation is repeated in each HTML page. Desktop links and a mobile menu built with the HTML details and summary elements provide access to the same six sections. CSS controls which menu is shown and adapts the card layouts to the available space.

Development Workflow

Work starts by inspecting the existing pages and styles, then making changes within a specific scope. Recent updates have included restoring Articles, publishing the first article, aligning the index pages, and refreshing the homepage.

I manually review and manage the Git workflow. Checks during these updates include reviewing diffs, checking local links and navigation, running git diff --check, and inspecting git status before staging or committing anything.

AI-Assisted Development

I'm experimenting with AI-assisted development as part of building the site. I use it to help implement scoped changes to HTML and CSS, then review the results and request adjustments to wording, structure, and presentation.

For the first article, the task was to turn my supplied text into HTML while preserving the wording and bold passages. For the homepage, the task was to feature real work already on the site and reuse the existing design.

Design Decisions

The homepage is a short introduction with links to one article, one paper, and one project. The section indexes follow a simple pattern: a title, a short introduction, and cards. Shared borders, colors, spacing, and typography keep those pages consistent.

Long-form pages use a narrower reading area instead of placing the whole write-up inside a card. The site stays lightweight, and the mobile navigation works without JavaScript.

What I've Learned

Working on the site has made consistency a practical concern. With navigation copied into each page, adding a section means checking every menu. Reusing shared styles makes it easier to keep the index pages aligned without duplicating CSS.

It has also been an exercise in reviewing the details: making sure cards point to the right pages, removing placeholders when real content is ready, preserving article text, and keeping changes focused on the task.

Current State / Next Steps

The site currently has Home, About, Projects, Articles, Papers, and Contact sections. The homepage features the Shodan article, the Proxmox paper, and this project. The Projects page also records the Arduino Network Scanner experiment.

The site is still growing, so I’ll keep adding new projects, articles, papers, and documentation as I work on them. This page will continue to evolve along with the site.
